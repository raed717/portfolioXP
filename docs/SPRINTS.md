# Sprint Plan — PortfolioXP

Source of truth for behaviour and visuals: [`THEME_CONTEXT.md`](../THEME_CONTEXT.md).
Each sprint is one week and ends with a deployable build that passes the §13 checklist.
The `/cv` fast path ships first and stays live in every sprint.

| Sprint | Theme | Outcome |
|---|---|---|
| 0 | Foundation | ✅ Project, architecture, data layer, stores, `/cv` fallback |
| 1 | Shell core | ✅ Boot → Login → Desktop with real draggable windows, taskbar, Start menu |
| 2 | Content apps | ✅ Every piece of portfolio content reachable through apps |
| 3 | Power apps | ✅ Terminal, Browser, Mail (with a server route) |
| 4 | Personality | ✅ Control Panel, themes, sounds, easter eggs, shutdown flow |
| 5 | Hardening & launch | a11y/perf audits, e2e tests, deploy |
| Stretch | Extras | Minesweeper, AI chat, FR translation, analytics |

- [x] App registry: `src/apps/registry.ts` (metadata + lazy loaders, extension → app map)
- [x] Zustand stores: `windows` (window manager), `preferences` (persisted), `session` (phase/persona)
- [x] Hooks: `useLayoutMode` (§9 breakpoints), `useReducedMotion` (OS + override)
- [x] Static semantic `/cv` page + `<noscript>` link
- [x] Vitest + RTL with 13 unit tests (window manager, VFS, data normalization)
- [x] Unused images removed from `public/images`

## Sprint 1 — Shell core ✅

- [x] Original icon set: 33 SVGs generated by `npm run icons` (`scripts/build-icons.mjs`), plus an original hills wallpaper
- [x] `<Experience />` phase machine (client-only via `next/dynamic`; the server fallback keeps the Quick View link)
- [x] Boot screen: skip by click, key or link; skipped for the rest of the session and under reduced motion. Restart / Power on replays it.
- [x] Login: Recruiter / Fellow Dev / Guest, Quick View link, Turn off
- [x] Window: `react-rnd` drag and resize, title bar double-click maximizes, viewport clamping, minimize animation, dialogs auto-size and never maximize
- [x] WindowManager: one `React.lazy` per app, an error boundary, and a friendly `UnavailableApp` for programs not built yet
- [x] Taskbar ("RG" Start button, task buttons, tray with mute toggle and clock), mobile window switcher
- [x] Start menu: two columns, All Programs, GitHub, Quick View, Log Off, Turn Off; arrow keys, Home/End, Esc, outside click
- [x] Turn Off dialog (Stand By / Turn Off / Restart), Stand By screen, Goodbye screen, blue-screen easter egg
- [x] Desktop icons: click selects, double-click opens, tap opens on touch/mobile, arrow-key navigation, tooltips
- [x] Responsive: tablet opens windows maximized; mobile has full-screen windows with a back button, a 44px bar and a 4-column grid
- [x] Personas launch their windows once per login
- [x] `aria-live` announcer; Alt+F4, Alt+Tab (or Alt+`` ` ``), Ctrl+Esc, Esc on dialogs
- [x] Pulled forward from Sprint 2: **Notepad** and the **Message** box (needed to test the shell end to end)
- [x] Tests: 23 (window store, VFS, data, launcher, experience flow)

**Notes**

- Tailwind preflight resets margins, list styles and link underlines. Prose surfaces (`/cv`, dialogs, BSOD) restore them explicitly.
- Real Alt+F4 / Alt+Tab are usually captured by the browser or OS; Alt+`` ` `` is the reliable alternative.
- Bundle: all JS chunks together are ~214 KB gzipped, including lazy app chunks. Measure the shell-only budget (< 200 KB) precisely in Sprint 5.

## Sprint 2 — Content apps ✅

Goal: every fact in `src/data` is reachable from the desktop.

- [x] `ui/` kit: Tabs (WAI-ARIA, arrow keys), ContextMenu (+ `useContextMenu` store). The Message app is the dialog; drive bars are plain CSS.
- [x] **Explorer:** back/forward/up, `C:\` address bar, task pane (project tasks, Other Places, details), icons/details views, empty-folder copy, keyboard (arrows, Enter, Backspace, Alt+←/→). The task pane hides in narrow windows via a container query.
- [x] **Notepad:** typewriter effect for the Guest's `about_me.txt`. Skippable, off under reduced motion, and screen readers get the full text.
- [x] **PdfViewer:** embedded résumé, Download, Open in new tab, fallback when the browser can't render PDFs.
- [x] **ImageViewer:** `next/image` (Cloudinary + local), previous/next, arrow keys, caption, "Open original".
- [x] **My Computer:** system summary plus skill groups as drives C:–F:. The bar is the group's share of listed skills, not a proficiency claim.
- [x] **Properties:** project folders get General / Tech Stack / Features / Links; files and folders get type, program, location, size, contents; shortcuts get a description.
- [x] **Context menus:** desktop (Refresh, New…, Properties), icons and files (Open, Properties), Explorer background (views, up, properties). Touch long-press works too.
- [x] Window `update()` action; iframe focus shield (`embedsFrame`) so PDF/Browser windows activate on first click and drags don't stall over them.
- [x] Tests: 35 (adds Explorer, Properties, ContextMenu, fileInfo)

## Sprint 3 — Power apps ✅

- [x] **Terminal** (`lib/terminal.ts` pure interpreter + `apps/terminal`):
  - Commands: help, about, projects, open, skills, experience, education, contact, mail, theme, ls/dir, cd, cat/type, start, pwd, whoami, echo, clear/cls, exit, hidden `sudo hire-me`.
  - XP prompt (`C:\My Documents>`), ↑/↓ history, Tab completion for commands, paths (quotes for spaces), project slugs and themes, Ctrl+L, Ctrl+C.
- [x] **Web Voyager:**
  - Favorites home page of live demos, back/forward/refresh/home, address bar, Open in new tab.
  - Allow-list of project URLs; anything else gets a friendly page.
  - `/api/embed-check` reads `X-Frame-Options` / CSP `frame-ancestors` server-side (allow-listed URLs only, cached 1h). Blocked sites show the project cover and an Open in new tab link.
  - Sandboxed iframe; Google Drive links are converted to `/preview`.
- [x] **Mail:**
  - Composer with "To: Raed Guembri" (no address), client and server validation from the shared `lib/contact.ts`, honeypot and time trap.
  - `POST /api/contact` rate-limits to 5 messages per 10 minutes per IP and delivers through Resend's REST API. It reads its configuration from `.env.local` (see `.env.example`). Without a key it logs in development and returns 503 in production.
- [x] **Privacy:** email and phone moved from `profile.json` to `content/contact.private.json`, imported only through `data/server/contact.ts` (`server-only`). Verified absent from `.next/static`.
- [x] **Projects ↔ experience:** `experienceCompany` in `projects.json` links SmarTown to WOLO and HR Assistant to Inoteqia. Role, period and results appear in README.txt and Properties.
- [x] `demo.exe` windows are titled by project.
- [x] Tests: 55 (adds terminal interpreter and completion, contact validation, rate limiter, both API routes)

**Embed results** (checked against the live sites): Iron Log, Albania Booking and the HR Assistant video embed. Mining Maps sends `X-Frame-Options: SAMEORIGIN`, so it opens with the preview and new-tab fallback.

## Sprint 4 — Personality ✅

- [x] **Control Panel:** Themes / Desktop / Sounds / Screen Saver / Accessibility tabs, applied instantly.
  - Skin previews are mini windows rendered with each skin's own tokens (`data-theme` on a nested element).
  - Wallpapers: Green Meadow (owner photo, launch blocker), Rolling Hills, Desert Dusk (new, original), Plain Blue.
  - Accessibility: reduce motion (system / on / off), show Flop, reset window positions, restore all defaults.
- [x] **Midnight** dark skin, plus fuller Olive and Silver skins (Start menu tokens included).
- [x] **Sounds** (`lib/sound.ts`): startup, shutdown, click, open, close, error, notify, synthesized with Web Audio. Original, 0 bytes, AudioContext created lazily on first use (always after a gesture), muted by default, mute respected everywhere.
- [x] **Screensaver:** 60s idle, bouncing logo and name with a hue shift on each edge hit, transform-only animation. Any input exits. Off under reduced motion or via Control Panel. Never triggers while focus is inside a demo iframe or the PDF.
- [x] **Flop**, the sidekick: an original floppy-disk character with persona-aware tips and actions (`data/sidekick.ts`). Appears after 15s; × hides it for the session, "Don't show again" persists. Steps aside for menus, dialogs, the screensaver and maximized or mobile windows.
- [x] **Window layout persistence:** last position and size per app in `localStorage` (`portfolioxp:layout`). Open windows are not restored, so persona launches stay predictable.
- [x] Preferences v2 migration (old `hills` = photo → `meadow`).
- [x] Already shipped earlier: shutdown flow, BSOD, `sudo hire-me`.
- [x] Tests: 64 (layout persistence, migration, idle, sidekick, Control Panel)

## Sprint 5 — Hardening & launch

1. Playwright e2e covering each persona flow, the mobile flow, keyboard-only use, and `/cv`.
2. Accessibility audit with axe: contrast of labels over the wallpaper and on title bars.
3. Performance: shell JS under 200 KB gzipped, Lighthouse targets (§11.5), preload Explorer and Notepad when idle.
4. SEO: metadata, OG image, sitemap, JSON-LD `Person` on `/cv`.
5. Deploy to Vercel and work through the §13 checklist.
